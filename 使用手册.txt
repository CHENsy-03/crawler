============================================================
  政府网站政策爬虫 - 小白运行手册 (V3.0)
============================================================

【一、这是干什么的】
自动去政府网站搜索关键词（低空经济、低空政策），找到政策文件并保存。
支持：北京市财政局、杭州市财政局、绍兴市财政局。

【二、安装】

1. 确保电脑安装了 Python 3.9+
2. 安装依赖（只需一次）：
   pip install requests lxml selenium

【三、最简单的搜索】

python main.py --site czj_beijing --keywords 低空经济

等待几秒，看到 [OK] 就成功了。结果在 output/ 目录下。

【四、内置站点】

  czj_beijing    北京市财政局（TRS API，最快）
  czj_hangzhou   杭州市财政局（JPAAS API）
  sxcs_shaoxing  绍兴市财政局（JPAAS API）

【五、杭州/绍兴搜索（JPAAS平台）】

python main.py --site czj_hangzhou --keywords 低空经济 --max-pages 1
python main.py --site sxcs_shaoxing --keywords 低空经济 --max-pages 1

这两个站用浙江省统一搜索平台，返回格式含 mapSearchResult 嵌套结构
和 content_556463 正文字段——程序已自动处理。

【六、常用命令】

  自检:          python main.py --self-test
  搜索:          python main.py --site czj_beijing --keywords 低空经济
  多关键词:      python main.py --site czj_beijing --keywords 低空经济 低空政策
  多页:          python main.py --site czj_beijing --keywords 低空经济 --max-pages 3
  获取正文:      python main.py --site czj_hangzhou --keywords 低空经济 --with-detail
  指定输出:      python main.py --site czj_beijing --keywords 低空经济 --output mydir
  URL列表抓取:   echo URL > urls.txt && python main.py --urls urls.txt
  探查新站:      python main.py --discover https://xxx.gov.cn
  查看帮助:      python main.py --help

【七、结果文件】

output/ 目录下生成：
  *.json  完整数据
  *.csv   表格格式（Excel可直接打开）

每篇文章包含：标题、网址、发布时间、关键词匹配分数。

【八、如果搜索结果为0】

1. JPAAS站（杭州/绍兴）：暂时加 --max-pages 1 避免超时
2. 如果曾多次测试同站：删 output\crawler.db（去重数据库）
3. filter_by_score 按 threshold 过滤，可调 extractor/scorer.py 中 THRESHOLD

【九、添加新网站】

1. 打开 config/sites_config.json
2. 按已有格式添加新站点（TRS用 trs_json，JPAAS用 jpaas_jsearch）
3. 直接用 --site 你的站点名 搜索

【十、目录结构】

main.py            入口程序
anti_crawler/      反爬层（令牌桶/熔断/UA池/延迟）
fetcher/           请求层（HTTP客户端/Session管理）
parser/            解析层（CSS->XPath->Regex三层回退）
extractor/         评分层（threshold评分/清洗）
dedup/             去重层（MD5 url_hash）
storage/           存储层（JSON/CSV/DuckDB）
scheduler/         调度层（队列/搜索+JPAAS）
analytics/         分析层（趋势/报告）
config/            配置文件
output/            输出目录
